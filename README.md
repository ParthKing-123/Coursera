# Paradise Nursery

Paradise Nursery is an online plant shop built as a shopping cart web application.
Users can browse plants, view details, add them to a cart, and manage their order.

## Features
- Landing page with company introduction and a "Get Started" button
- Product listing page with plant images, names, descriptions, and prices
- Plants organized by category
- "Add to Cart" button (disabled once a plant is in the cart)
- Navigation bar with a live cart item count
- Shopping cart page showing each item's thumbnail, name, unit price, and quantity
- Increase/decrease quantity buttons and a delete option
- Total cost calculated for each item and for the whole cart
- Checkout button (coming soon) and Continue Shopping button

## Tech Stack
- React
- Redux Toolkit (state management)
- JavaScript, HTML, CSS

## Getting Started
1. Clone the repo: `git clone https://github.com/<your-username>/<your-repo-name>.git`
2. Install dependencies: `npm install`
3. Run the app: `npm start`
